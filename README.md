# Банківське кредитування (Варіант №12) — Лабораторна робота №4

## Результати бенчмарку пошуку (`SearchBenchmark`)
Умови тестування: **100 000 об'єктів** `Borrower`, **1 000 пошукових запитів** за прогін (з урахуванням існуючих та відсутніх ключів), 5 прогрівів JVM, 15 вимірювальних прогонів, логування вимкнено.

| Структура даних | Складність пошуку за ключем | Медіанний час (1 000 запитів) | Прискорення |
| :--- | :---: | :---: | :---: |
| `GenericRepository` (`LinkedHashMap`) | $O(1)$ | **0.4836 ms** | **1540.8x** |
| `ArrayList` (лінійний перебір) | $O(N)$ | **745.13 ms** | $1\times$ |

### Висновок
Використання хеш-таблиці (`Map<String, T>`) усередині `GenericRepository<T>` забезпечує сталий час пошуку за унікальним ключем ($O(1)$) незалежно від розміру репозиторію, тоді як лінійний пошук у списку ($O(N)$) потребує в середньому $N/2$ порівнянь на кожен знайдений елемент і повного проходу всіх 100 000 елементів для відсутніх ключів. Прогрів JVM та обчислення медіани дозволяють усунути вплив JIT-компіляції та пауз збирача сміття (GC).
