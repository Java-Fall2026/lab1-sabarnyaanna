# Використання AI у лабораторній роботі №6

Під час виконання лабораторної роботи №6 я використовувала AI-асистента Gemini як консультанта для інтеграції Jackson (JSON/YAML), Jakarta Validation (Hibernate Validator) та побудови конвеєра завантаження `DataLoader` для 12-го варіанта («Банківське кредитування»). Ключовий промпт: «Поясни, як реалізувати узагальнений FileStorage<T> для JSON і YAML з ISO-датами, власну перехресну анотацію Jakarta Validation та DataLoader із LoadResult без падіння програми на невалідних файлах».

На основі отриманих пояснень я самостійно налаштувала залежності в `build.gradle`, створила `app.properties` і `AppConfig`, реалізувала перехресну анотацію `@ValidLoanLimit` з `ValidLoanLimitValidator`, створила набори даних у `data/` (15 записів у JSON і YAML + `broken.json`) і написала 7 тестів у `BankLab6Test` з `@TempDir`. Під час доопрацювання я прибрала дублюючі винятки з конструкторів сутностей, щоб Jackson міг десеріалізувати невалідні записи для подальшої перевірки валідатором, та виправила старі тести ЛР №3, які очікували виняток прямо з конструктора.
